Bookhoarder is a self-hosted EPUB library: upload books, read them in the
browser, and keep track of what you and anyone else on the install are
reading — all backed by object storage, with no database underneath it.

<CardGrid>
  <Card title="Library & Reading" icon="ph:book-open">
    Upload, dedupe, and read EPUBs in the browser, with progress and
    ratings saved per profile. See [Library & Reading](/features/library).
  </Card>
  <Card title="Shelves" icon="ph:stack">
    Group books into shelves — five to start, and as many more as you
    want. See [Shelves](/features/shelves).
  </Card>
  <Card title="Profiles & Access" icon="ph:users">
    Multiple readers per install, admin/reader roles, optional per-profile
    passwords. See [Profiles & Access](/features/profiles).
  </Card>
  <Card title="Send to E-Reader" icon="ph:paper-plane-tilt">
    Email any book straight to a Kindle or other e-reader over SMTP. See
    [Send to E-Reader](/features/send-to-ereader).
  </Card>
  <Card title="Metadata & Discovery" icon="ph:sparkle">
    Open Library metadata lookup, cover fetching, and a trending shelf to
    find what to read next. See [Metadata & Discovery](/features/metadata-and-discovery).
  </Card>
  <Card title="OPDS Catalog" icon="ph:rss">
    Browse and download your library directly from any OPDS-compatible
    e-reader app. See [OPDS Catalog](/features/opds).
  </Card>
  <Card title="Library Backup" icon="ph:archive">
    Admin-only streaming zip export of your library's metadata, or
    metadata plus every file. See [Library Backup](/features/backup).
  </Card>
  <Card title="Install as an App" icon="ph:device-mobile">
    Install Bookhoarder as a standalone app on desktop or mobile. See
    [Install as an App](/features/pwa).
  </Card>
</CardGrid>
