<Steps>
  <Step title="Start with the defaults">
    Every profile gets five shelves the first time it's used: Fiction,
    Non-Fiction, Sci-Fi & Fantasy, Biography, and To Read. Rename, recolor,
    or delete any of them.
  </Step>
  <Step title="Add books to a shelf">
    From a book's menu, toggle it onto one or more shelves.
  </Step>
  <Step title="Browse a shelf">
    Open it from the sidebar to see just the books on it.
  </Step>
</Steps>

## How shelves work

- Shelves are per-profile — two profiles on the same install never share
  a shelf, even if they name one the same thing
- A book can be on any number of shelves at once
- Adding a book to a shelf it's already on is a no-op, so there's no need
  to check before toggling it
- Create as many additional shelves as you want, each with its own name
  and color

Shelves only organize books you've already uploaded — see
[Library & Reading](/features/library) for adding books, and
[Metadata & Discovery](/features/metadata-and-discovery) for finding new
ones.
