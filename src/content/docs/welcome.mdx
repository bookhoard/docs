Bookhoard is a self-hosted EPUB library. Upload books, read them in the
browser, track progress per reader profile, and search your collection —
all backed by object storage, with no database and nothing to migrate.

<Aside type="note" title="No database">
  Bookhoard's only persistence layer is object storage: the local
  filesystem, or an S3-compatible bucket (AWS S3, MinIO, Cloudflare R2,
  Backblaze B2, ...). There's no database to provision, back up, or
  migrate between versions.
</Aside>

## What you get

<CardGrid>
  <Card title="EPUB reader" icon="ph:book-open">
    In-browser reading via epub.js, with per-profile progress, ratings,
    and shelves.
  </Card>
  <Card title="Multi-profile" icon="ph:users">
    Admin and reader roles, with optional per-profile passwords.
  </Card>
  <Card title="Metadata + covers" icon="ph:magnifying-glass">
    Lookup and cover fetching via Open Library, with manual editing.
  </Card>
  <Card title="Pluggable storage" icon="ph:hard-drives">
    Local filesystem or any S3-compatible bucket, with a configurable
    prefix for sharing a bucket with other apps.
  </Card>
</CardGrid>
